2. OOP + NumPy: Stock Portfolio Analyzer
Concept: Build a small investment/stock analysis program using OOP + NumPy arrays.

You don't need real-time stock APIs. Start with manually entered historical prices.

Features
Create a stock
Store historical prices in a NumPy array
Calculate:
Average price
Maximum price
Minimum price
Daily returns
Standard deviation
Compare two stocks
Calculate portfolio value
Find the best-performing stock
